# 仕事スタイル16タイプ診断

24の質問から、仕事における考え方や行動傾向を
4軸・16タイプで可視化するWebアプリです。

[▶ 診断を試す](ここにStreamlitのURL)

![アプリ画面](docs/images/app-preview.png)

## 制作背景

仕事の適性を一つのタイプで断定するのではなく、
4軸の比率から自分の傾向を理解できる診断を目指して制作しました。

## 工夫した点

- 正方向・逆方向の設問を混在させ、回答の偏りを抑制
- 4軸を比率として可視化し、傾向の強さまで表現
- 設問、採点処理、結果文を分離して保守性を向上
- 16タイプそれぞれに独自の名称とキャラクターを設計
- 採点ロジックと画面遷移を自動テスト
