# 仕事スタイル16タイプ診断

24の質問から、仕事における考え方や行動の傾向を4軸・16タイプで整理するStreamlitアプリです。

## 4つの軸

| 軸 | 左側 | 右側 |
|---|---|---|
| 判断の起点 | 現実重視（R） | 理想重視（V） |
| 仕事の進め方 | 計画型（P） | 柔軟型（F） |
| 周囲との関わり方 | 個人型（I） | 協働型（C） |
| 価値の生み出し方 | 既存改善型（E） | 新規開拓型（N） |

## 主な機能

- 24問を8問ずつ、全3ページで表示
- 診断内容と4軸を紹介するスタート画面
- 5段階回答と未回答チェック
- 賛成方向が異なる逆転項目を自動採点
- 各軸を0〜100の傾向スコアとして表示
- 50対50はそのまま均衡として表示し、追加質問なしで結果へ遷移
- 4文字コードと日本語名で16タイプに分類
- 16タイプごとのオリジナルキャラクターを結果画面に表示
- 強み、注意点、チームでの役割、力を発揮しやすい環境を表示
- 採点ロジックの自動テスト
- Streamlitの画面遷移テスト

## ファイル構成

```text
work_style_diagnosis/
├── app.py                 # 画面とページ遷移
├── questions.py           # 軸・設問・加点方向
├── scoring.py             # 採点とタイプ判定
├── types_data.py          # 16タイプの結果文
├── assets/characters/     # 16タイプのキャラクター画像
├── requirements.txt       # 必要なライブラリ
├── .streamlit/
│   └── config.toml        # 配色などのテーマ設定
└── tests/
    ├── test_scoring.py    # 採点ロジックのテスト
    └── test_app.py        # 最初の画面遷移テスト
```

設問、採点、結果文を分離しているため、文章を修正しても採点処理を壊しにくい構成です。

## キャラクターデザイン

16タイプは、紙細工のような非人間型キャラクター「Workling」で表現しています。現実重視は四角、理想重視は星、計画型は直線と段階、柔軟型は曲線とリボン、個人型は一つの核、協働型は複数の仲間、既存改善型は修理、新規開拓型は扉や光を共通モチーフとしています。

## ローカルでの実行

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

macOS / Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## テスト

```bash
pytest -q
```

テストでは、全問中立、各極への最大回答、質問順の変更、50対50の追加回答、表示比率の合計を確認します。

## 採点方法

回答は内部で1〜5として保持し、0・25・50・75・100点へ変換します。各質問の `agree_pole` に応じて加点方向を反転し、軸ごとの6問を平均します。反対側のスコアは `100 - first_pole_score` で算出します。

## 注意事項

この診断は自己理解を支援するオリジナルコンテンツです。医学的・心理学的診断や、特定の職業への適性を保証するものではありません。
